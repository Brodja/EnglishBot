# 🔑 Налаштування Google Sheets API

## Чи потрібен API Key?

**Коротка відповідь: НІ, не обов'язково!**

Наш бот працює з **публічними** Google Sheets таблицями без API Key. Однак, API Key дає такі переваги:
- 🚀 Збільшені ліміти запитів (100 запитів/хв замість 100 запитів/день)
- 🛡️ Більша надійність та стабільність
- 📊 Можливість працювати з приватними таблицями (з додатковою настройкою)

## 🆓 Без API Key (простий спосіб)

Просто не додавайте `GOOGLE_SHEETS_API_KEY` в `.env` файл. Бот буде працювати з публічними таблицями.

**Вимоги:**
- Таблиця має бути **публічною** (доступ "Будь-хто з посиланням може переглядати")
- Обмеження: 100 запитів на день

## 🔑 З API Key (рекомендовано)

### Крок 1: Створення проекту в Google Cloud Console

1. Перейдіть на [Google Cloud Console](https://console.cloud.google.com/)
2. Увійдіть в свій Google акаунт
3. Натисніть на випадаючий список проектів (зверху зліва)
4. Натисніть **"New Project"** 
5. Введіть назву проекту: `English Telegram Bot`
6. Натисніть **"Create"**

### Крок 2: Увімкнення Google Sheets API

1. В лівому меню: **"APIs & Services"** → **"Library"**
2. В пошуку введіть: `Google Sheets API`
3. Натисніть на **"Google Sheets API"**
4. Натисніть **"ENABLE"**

### Крок 3: Створення API Key

1. Перейдіть: **"APIs & Services"** → **"Credentials"**
2. Натисніть **"+ CREATE CREDENTIALS"**
3. Виберіть **"API key"**
4. **Скопіюйте згенерований ключ!**

### Крок 4: Обмеження API Key (безпека)

1. Натисніть **"RESTRICT KEY"** біля створеного ключа
2. В розділі **"API restrictions"**:
   - Виберіть **"Restrict key"**
   - Поставте галочку біля **"Google Sheets API"**
3. В розділі **"Application restrictions"** (опціонально):
   - Можете залишити **"None"**
   - Або обрати **"IP addresses"** та додати IP вашого сервера
4. Натисніть **"SAVE"**

### Крок 5: Додавання в проект

Додайте ключ в ваш `.env` файл:

```env
GOOGLE_SHEETS_API_KEY=AIzaSyC-ваш_реальний_ключ_тут
```

## 📊 Налаштування Google Sheets таблиці

### 1. Створення таблиці
1. Перейдіть на [Google Sheets](https://sheets.google.com/)
2. Створіть нову таблицю
3. Назвіть її, наприклад: "English Words"

### 2. Структура даних
Організуйте дані так:

| A | B (English) | C | D (Переклад) |
|---|-------------|---|--------------|
| № | hello       |   | привіт       |
| 1 | world       |   | світ         |
| 2 | computer    |   | комп'ютер    |

**Важливо:**
- Англійські слова **ОБОВ'ЯЗКОВО** в колонці **B**
- Переклади **ОБОВ'ЯЗКОВО** в колонці **D**
- Колонки A та C можуть містити будь-що або бути порожніми

### 3. Публікація таблиці
1. Натисніть **"Поділитися"** (Share)
2. В розділі **"Загальний доступ"** натисніть **"Змінити"**
3. Виберіть **"Будь-хто з посиланням"**
4. Переконайтеся що встановлено **"Читач"** (Viewer)
5. Натисніть **"Готово"**
6. Скопіюйте посилання

## ⚠️ Можливі проблеми

### "The caller does not have permission"
- Переконайтеся що таблиця публічна
- Перевірте що API Key правильний
- Переконайтеся що Google Sheets API увімкнений

### "Invalid API key"
- Перевірте що ключ скопійований повністю
- Переконайтеся що немає зайвих пробілів
- Перевірте що API key не обмежений неправильно

### "Quota exceeded"
- Без API Key: ліміт 100 запитів/день
- З API Key: ліміт 100 запитів/хвилину
- Зачекайте або створіть новий API Key

### Таблиця порожня
- Перевірте що дані в колонках B та D
- Переконайтеся що перший рядок не порожній
- Перевірте що таблиця не приватна

## 💡 Корисні поради

1. **Без API Key достатньо** для особистого використання
2. **З API Key** - якщо планується активне використання
3. **Завжди робіть таблиці публічними** для роботи бота
4. **Регулярно робіть backup** ваших таблиць
5. **Не діліться API Key** з іншими людьми
