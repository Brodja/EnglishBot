# 🚀 Швидкий старт

## 1. Встановлення залежностей

### Windows:
```bash
install.bat
```

### Linux/macOS:
```bash
chmod +x install.sh
./install.sh
```

### Або вручну:
```bash
npm install
```

## 2. Налаштування змінних середовища

Створіть файл `.env` в корені проекту:

```env
API_KEY=ваш_токен_telegram_бота
MONGO_URI=mongodb://localhost:27017/englishbot
GOOGLE_SHEETS_API_KEY=ваш_google_api_key_тут_опціонально
NODE_ENV=development
PORT=3000
```

> **Примітка:** `GOOGLE_SHEETS_API_KEY` не обов'язковий! Бот працює з публічними таблицями і без нього. Детальні інструкції в файлі [GOOGLE_SHEETS_SETUP.md](GOOGLE_SHEETS_SETUP.md)

### Як отримати токен Telegram бота:
1. Знайдіть @BotFather в Telegram
2. Надішліть `/newbot`
3. Введіть назву бота
4. Введіть username бота (має закінчуватися на 'bot')
5. Скопіюйте отриманий токен в `.env`

## 3. Запуск MongoDB

### Docker:
```bash
docker run -d -p 27017:27017 --name mongodb mongo:latest
```

### Локально (Ubuntu/Debian):
```bash
sudo systemctl start mongod
```

### macOS:
```bash
brew services start mongodb-community
```

## 4. Запуск бота

```bash
npm run start:dev
```

## 5. Налаштування Google Sheets

1. Створіть Google Sheets таблицю
2. Зробіть її публічною (Поділитися → Змінити доступ → Будь-хто з посиланням)
3. Додайте дані:
   - **Колонка B**: Англійські слова
   - **Колонка D**: Переклади

Приклад структури:
```
| A | B (English) | C (Транскр.) | D (Переклад) | E (Приклади) | F (Вивчено) |
|---|-------------|--------------|--------------|--------------|-------------|
| № | English     | Transcription| Переклад     | Examples     | Learned     |
| 1 | hello       | /həˈloʊ/     | привіт       | Hello world! |             |
| 2 | world       | /wɜːrld/     | світ         | Big world    | ✓           |
| 3 | computer    | /kəmˈpjuːtər/| комп'ютер    |              |             |
| 4 | weak        | /wiːk/       |              | I'm weak     | learned     |
```

**Важливо:**
- Англійські слова **ОБОВ'ЯЗКОВО** в колонці **B**
- Колонка **C** - транскрипція (опціонально)
- Переклади в колонці **D** (можуть бути пустими)
- Колонка **E** - приклади речень (опціонально)
- Колонка **F** - маркер вивчених слів (якщо є будь-який текст - слово ігнорується)
- Якщо переклад відсутній, бот покаже "[переклад відсутній]"

**💡 Як позначати вивчені слова:**
- Поставте галочку ✓ в колонці F
- Напишіть "вивчено", "learned", "done"
- Або просто будь-який текст - бот зрозуміє

## 6. Використання бота

1. Знайдіть вашого бота в Telegram
2. Надішліть `/start`
3. Натисніть "🔗 Додати посилання"
4. Надішліть посилання на вашу Google Sheets
5. Натисніть "📚 Перейти до навчання"
6. Розпочинайте вивчення слів!

## ❗ Можливі проблеми

### "Cannot find module" помилки
```bash
rm -rf node_modules package-lock.json
npm install
```

### MongoDB не запускається
- Перевірте чи встановлений MongoDB
- Перевірте чи правильний MONGO_URI в .env

### Бот не відповідає
- Перевірте токен в .env
- Переконайтеся що бот запущений
- Перевірте логи в консолі

### Google Sheets не працює
- Переконайтеся що таблиця публічна
- Перевірте структуру даних (колонки B та D)
- Переконайтеся що URL правильний

## 📞 Підтримка

Якщо виникають проблеми, перевірте:
1. Всі залежності встановлені (`npm install`)
2. Файл `.env` створений та заповнений
3. MongoDB запущений
4. Google Sheets таблиця публічна та правильно структурована
